# Продукт Open

Справочник продуктовых правил, не список готовых функций. Вход по задаче — [карта](map.md).
Читай выбранный раздел; оглавление: `node .agents/scripts/read-doc.mjs docs/product.md`.

## Идея продукта

**Open** — мессенджер, в котором переписка публична, и соцсеть, растущая из переписки.

Две равные опоры:

- **Мессенджер** как Telegram (лички, группы, фото, видео, голосовые, кружки, звонки), но любой
  чат может прочитать кто угодно и оставить реакцию/комментарий — всегда, без настройки на
  отключение.
- **Лента рекомендаций** — фрагменты чужих диалогов, посты, клипы со стримов. Здесь находят друг
  друга и подписываются.

Связь: пользователь создаёт контент самим фактом общения. Любое сообщение/медиа/звонок может
завируситься в ленту; можно публиковать и осознанно — в профиле. Звонок автоматически становится
публичным стримом: любой подключается слушателем, из него нарезаются клипы.

Честность: приложение явно показывает, что пользователь «на сцене», а не прячет публичность.

## Границы продукта

- не форум и не сеть одних постов: единица контента — сообщение в чате; чужой видит переписку
  как переписку (пузыри, аватары, хронология), не статью;
- публичность не делает посторонних участниками: комментарий/реакция снаружи — отдельный слой,
  не смешивается с сообщениями; писать в чат может только участник;
- лента и мессенджер равноценны: «это же просто мессенджер» и «это соцсеть, чат попроще» —
  неверно в обе стороны.

## Контент и медиа

- Любое сообщение — потенциально публичный контент: медиа с превью/метаданными, сообщения с
  контекстом, чтобы фрагмент читался в отрыве от переписки.
- Метаданные файлов (GPS, модель, даты, XMP/IPTC, udta/meta) вычищаются из каждого файла —
  правило для всех. Любая загрузка: `uploads` → Edge Function `sanitize-media` → чистый файл на
  постоянное место + запись в `media_objects`; база принимает в сообщения/комментарии/попсы/фото
  только файлы владельца из `media_objects` (OPN14). Не очистилось — не публикуется; исходные
  метаданные не хранятся нигде.

## Права записи и обещания приватности

- «Публично читаемо» ≠ «публично записываемо»: право записи проверяется на сервере всегда.
- E2E-шифрования нет и не будет; интерфейс не обещает приватности — ни словом, ни иконкой замка.

## Подписки и друзья

- Подписки — механика ленты, не только профиля. **Отложено:** подписок на людей нет (только на
  канал/чат, `subscriptions`); у профиля нет кнопки «Подписаться» и счётчика подписчиков.
  **Друзья ≠ подписки:** дружба взаимна (`friendships`), даёт вариант «только друзьям», в
  ленту/ранжирование не идёт. Слова «контакт» в интерфейсе нет.

## Видимость людей

- Приватность — настройками: каждая видимость применяется только через
  `privacy_allows(настройка, владелец, зритель)`; значения по возрасту — только
  `privacy_default_settings(подросток)`.
- Человек показывается только через `person_card(человек, зритель, чат)` — имя, username, фото,
  «О себе», статус, id. Колонки `profiles` клиенту закрыты; любая функция/представление/рассылка с
  человеком зовёт `person_card` (вне диалогов — чат null), клиент читает людей из `profile_cards`,
  `message_rows`, `comment_rows`, `reactor_rows`, `chat_rows`, `chat_people` и т.п., не из
  `profiles`. В диалоге id бывает непрозрачным (`opaque`) — профиль не открывать, «в сети» не
  спрашивать; настоящий id подменённого не уходит посторонним ни в одном поле.
- Подростка незнакомому взрослому не рекомендовать нигде (лента, фрагменты, «кого добавить»,
  подсказки). Каталога всех пользователей нет: людей находят поиском с `account_search_visibility`
  или среди знакомых; поиск/списки людей — по частоте (`search_rate_hit`) и страницами.

## Удаление и блокировки

- Удаление контента мягкое (`deleted_at`): сообщение может быть процитировано в фрагменте/клипе.
- Медиа тяжёлое и публичное: CDN и экономия трафика — базовое требование, не «потом».
- Модерация/блокировки — часть модели. Блокировка в любую сторону — `blocked_pair` (с аккаунтами
  устройства заблокированного), автоограничение — `contact_restricted`; новое «обратиться к
  человеку» зовёт обе.
- Личку не-другу начинают заявкой — правило для всех: одно текстовое сообщение, до принятия чат
  видят только двое (`chats.request_pending`).

## Видимость сообщений

- Текст сообщения — глазами смотрящего: участник видит оригинал, остальные — `public_text`
  (скрытое автором `hidden_ranges` замазано «•» той же длины). Выбор — одна
  `message_seen_text(текст, текст для зрителей, участник)`; новое место, где текст уходит наружу,
  берёт его оттуда, не из `messages.text`. Скрывать можно только своё.
- Неопубликованное зрителям не выдаётся ничем: видимость — `chat_public_hold` + `message_seen`,
  время зрителю — `public_at`. Сигнал о сообщении в общий топик — `message_signal_topic(чат, seq)`
  (о чате — `chat_signal_topic`): о неопубликованном — только в `chat-members:<id>`. Висящее на
  сообщении (вложения, комментарии, реакции, цитаты, закрепы) зрителю — через `target_seen(цель)`.
